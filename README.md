# VoiceAudit — kho làm việc của nhóm

- Nhánh `main`: tài liệu hệ thống + mã chung (đo, kiểm, ghép thử). Nhánh `lane/p1` … `lane/p5`: `main` + mã riêng của lane.
- Clone đúng nhánh của mình vào **đường ngắn**: `git clone -b lane/p3 --single-branch <url> D:\VoiceAudit`.
- Dữ liệu **không** nằm trong git: tải gói `du_lieu_<Px>` nhóm trưởng gửi, giải nén vào chính thư mục này (gộp thư mục).
- Bắt đầu: `lanes/BAT_DAU.md` mục 10 (cài đặt) và mục 11 (ngày đầu).
